# Security checklist

The Phase 4.4 acceptance: each control, how it is enforced, and the evidence that it holds. Every
row's evidence can be run again. Results are from the development PC on 2026-11-18 unless a row
says otherwise. Re-run the whole list before launch and after any change to auth, tenancy or
storage, and keep this file current.

Status: **PASS** = done and verified here, **ACCEPTED** = a known limit with a reason,
**OPEN** = still to do before launch.
